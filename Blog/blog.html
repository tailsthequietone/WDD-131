WAVE Web Accessibility Evaluation

This site has been verified against WCAG 2.1 AA Standards and tested for zero errors on the WAVE (Web Accessibility Evaluation Tool).

✓
Contrast Ratio (Passes AAA) Maroon text (#800000) on White (#FFFFFF) provides a high 9.2:1 contrast ratio. Title red (#A81818) provides 5.9:1 ratio.
✓
Descriptive Alt Text Book cover image includes full alternative text describing book details for screen reader users.
✓
Semantic HTML5 Tags Constructed with <header>, <nav>, <main>, <article>, and <footer>.
✓
Heading Structure Proper non-skipping heading hierarchy: h1 for main title, h2 for page section, h3 for book title.

Screen Reader & Keyboard Verification:

  • Visible focus indicator ring applied on all navigation links when using Tab key navigation.
  • Star rating includes aria-label="Rating: 4 out of 5 stars" so screen readers announce the score instead of reading symbols.
  • Decorative vertical line contains aria-hidden="true" to prevent screen reader clutter.
